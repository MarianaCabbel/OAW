Lector RSS de Noticias

Resumen actualizado del flujo de obtención, almacenamiento y visualización de múltiples fuentes RSS con arquitectura separada por capas.

1) Flujo general actualizado

  • El usuario accede a index.php, que carga la vista principal de noticias.
  • El backend prepara el estado de la página (filtros, feeds, noticias, mensajes) y luego renderiza una plantilla HTML.
  • La sincronización RSS se ejecuta bajo demanda con el botón Refrescar (ya no se bloquea la carga inicial con sincronización automática).
  • Las noticias se guardan con INSERT ... ON DUPLICATE KEY UPDATE usando guid derivado de md5(link).
  • La UI permite filtrar por fuente y categoría, buscar por texto y ordenar por fecha/título/categoría.

2) Sincronización y parseo RSS

  • Gestión de fuentes: El modal de ajustes permite CRUD completo sobre la tabla feeds.
  • Descarga: Se usa cURL y fallback a file_get_contents con timeout y user-agent.
  • Parser genérico: Compatible con estructuras RSS distintas (por ejemplo Xataka y El Pais), leyendo campos como description, content:encoded, dcterms:alternative, category, dc:creator y media:content.
  • Medios: Se guarda solo imagen válida en image_url; se descartan formatos de video/audio (como .mp4).
  • Normalización: Se limpia HTML, se decodifican entidades y se normaliza texto UTF-8.

3) Arquitectura actual

  • Presentación HTML: templates/html/news-list.html con placeholders para contenido dinámico.
  • Entry point PHP: templates/html/news-list.php (bootstrap mínimo).
  • Lógica de página: scripts/php/news_page_logic.php (estado, filtros, sincronización, CRUD de feeds).
  • Renderer: scripts/php/news_page_renderer.php (inyecta datos en la plantilla HTML).
  • JS desacoplado: scripts/js/news-list.js para modales y comportamiento de carga.
  • Datos: MySQL con tablas feeds y news; uso de consultas preparadas en operaciones críticas.

4) UI, filtros y experiencia de carga

  • Filtros avanzados: Modal dedicado para seleccionar fuente, categoría y ordenamiento.
  • Refresco contextual: El botón Refrescar sincroniza de acuerdo con la fuente seleccionada (o todas si aplica).
  • Skeleton: Se muestra estado de carga inicial y se oculta al completar carga del DOM.
  • Ajustes RSS: Modal (icono de engrane) para alta, edición y eliminación de fuentes.
  • Límite de listado: La consulta principal muestra hasta 50 noticias por carga (acotada a máximo 100 en repositorio).
