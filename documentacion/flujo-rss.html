Lector RSS de Noticias

Resumen del flujo de obtención, almacenamiento y visualización de noticias desde la fuente RSS de Xataka México.

1) Flujo general

  • El usuario entra a la página principal de noticias y se carga la vista de listado.
  • La aplicación valida conexión a base de datos y asegura la estructura mínima de tablas usando el archivo create.sql.
  • Si no hay noticias o si se solicita sincronización manual, se descarga el RSS y se procesa cada item.
  • Las noticias se guardan en MySQL con estrategia de actualización por guid (insertar nuevas / actualizar existentes).
  • Finalmente se consultan los registros en base de datos y se renderizan en la UI con filtro por título.

2) ¿Cómo funciona la actualización de noticias?

  • Fuente RSS: se consume https://www.xataka.com.mx/feedburner.xml.
  • Descarga: primero se intenta por cURL; si no está disponible, se usa file_get_contents.
  • Parseo: se interpreta XML, se extraen título, enlace, guid, fecha, autor, imagen y descripción.
  • Normalización: se limpia HTML de la descripción y se corrige codificación UTF-8 para evitar texto corrupto.
  • Persistencia: se ejecuta un INSERT ... ON DUPLICATE KEY UPDATE para mantener noticias al día.
  • Ejecución: la sincronización ocurre por primera carga (si no hay datos) o por acción manual en la UI (botón Sincronizar RSS).

3) Arquitectura de la app (alto nivel)

  • Capa de presentación: plantilla HTML/CSS del listado de noticias y buscador.
  • Capa de aplicación: scripts PHP para sincronizar RSS, consultar noticias y orquestar el flujo.
  • Capa de datos: conexión MySQL y esquema SQL inicial.
  • Punto de sincronización: endpoint dedicado para ejecutar actualización bajo demanda.
  • Manejo de errores: errores y excepciones relevantes se registran en el log de PHP.

4) Componentes principales

  • database/create.sql: define estructura inicial de base de datos.
  • database/connection.php: conexión MySQL con charset utf8mb4.
  • scripts/php/rss_sync.php: lógica de descarga y parseo RSS.
  • scripts/php/news_repository.php: operaciones de tabla y consultas de noticias.
  • scripts/php/sync_news.php: endpoint para sincronización manual.
  • templates/html/news-list.php: render del listado y búsqueda.
