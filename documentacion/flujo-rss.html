Lector RSS de Noticias

Resumen del flujo de obtención, almacenamiento y visualización centralizada de múltiples fuentes RSS.

1) Flujo general

  • El usuario gestiona sus fuentes personalizadas añadiendo URLs de RSS directamente desde la interfaz.
  • La aplicación valida la conexión a la base de datos y asegura que las tablas news y feeds estén listas.
  • Al solicitar la sincronización ("Actualizar Todo"), la aplicación recorre todos los feeds almacenados y procesa cada ítem.
  • Las noticias se guardan en MySQL utilizando un INSERT ... ON DUPLICATE KEY UPDATE para mantener los datos actualizados mediante el identificador único guid.
  • La interfaz permite al usuario buscar noticias por título/descripción y ordenarlas dinámicamente por fecha, título o categoría.

2) Actualización de noticias

  • Gestión de Fuentes: Los usuarios pueden registrar múltiples URLs en la tabla feeds.
  • Descarga: Se utiliza cURL con una configuración de timeout para obtener el contenido, respaldado por file_get_contents.
  • Parseo Dinámico: Se interpreta el XML, extrayendo los metadatos habituales y capturando la categoría de cada noticia.
  • Normalización: Se limpia el HTML de las descripciones y se normaliza el texto a UTF-8 para garantizar legibilidad.
  • Persistencia: La estrategia de actualización asegura que, ante cambios en un artículo (ej. edición de título), la noticia en base de datos se mantenga vigente.

3) Arquitectura de la aplicación

  • Capa de presentación: Interfaz con formularios para añadir feeds, buscador por texto y selectores de ordenamiento (Fecha, Categoría, Título).
  • Capa de aplicación: Lógica centralizada para orquestar la sincronización de múltiples fuentes y consultas optimizadas a base de datos.
  • Capa de datos: Base de datos MySQL con tablas relacionales separadas para feeds y news.
  • Seguridad: Uso estricto de prepared statements en todas las consultas para prevenir inyecciones SQL.

4) Componentes principales

  • database/create.sql: Esquema de tablas con soporte para categorías y gestión de feeds.
  • rss_sync.php: Lógica robusta de descarga y parseo de múltiples orígenes.
  • news_repository.php: Operaciones CRUD, incluyendo la nueva lógica de búsqueda y ordenamiento dinámico.
  • news-list.php: Vista principal que orquestra la UI, el registro de nuevos feeds y el filtrado en tiempo real.
